# hero-icons

Free GitHub-hosted skin icons for Sharp-Hero.

- Version folder: `v3/`
- Format: PNG 48x48
- Count: 635
- Base URL (raw): `https://raw.githubusercontent.com/matheustx017/hero-icons/main/v3/`
- Base URL (jsDelivr): `https://cdn.jsdelivr.net/gh/matheustx017/hero-icons@main/v3/`

Regenerate from Sharp-Hero:

```bash
python tools/publish_icons.py --repo matheustx017/hero-icons --push
```
